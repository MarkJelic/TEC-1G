# TMS9918 Video Card for TEC-1G TEC-Deck

Please note that verison 1.1 of the PCB did work perfectly, except the address range for the Ports was wrong. Hence there are some Cuts & Bodges  (https://github.com/MarkJelic/TEC-1G/blob/main/TEC-Deck/TMS9918_Video/Cuts-%26-Bodges_v1-1.jpg) you need to do to make it work correctly.  (Yellow lines are cuts on the front (red) and back (green) copper traces. Pink is for the bodge wires you need to add after you finish doing the main soldering.)

Verison 1.2 of the PCB fixes these issues and makes the circuit even simpler.

Note that as with all PCBs moving forward, you can use either through hole or SMD components.

Try the demo that "Damian Damian" wrote, in the Examples folder. A full API for MON3 is being developed.
