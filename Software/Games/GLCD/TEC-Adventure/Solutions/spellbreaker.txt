AIM: TO COLLECT ALL THE "CUBES" AND DEFEAT THE SHADOWY FIGURE

NOTE 1: SPELLS  MAY FAIL,  ESPECIALLY  EARLY IN  THE GAME.  IF A  SPELL FAILS,
LEARN IT AGAIN AND RETRY.
NOTE 2: WHEN  YOU SLEEP, ALL MEMORIZED  SPELLS  ARE FORGOTTEN — RE- LEARN THEM
AFTER WAKING.

COUNCIL CHAMBER (START)
-----------------------
DROP KNIFE, WAIT, WAIT, WAIT,  S, GET  ALL, S, READ  BOOK  [15], LEARN LESOCH,
LESOCH, GET  CUBE  [25], FROTZ  ME, "LEARN  BLORPLE, BLORPLE, BLORPLE",  WRITE
"earth" ON CUBE, BLORPLE "earth"

PACKED EARTH — GETTING THE ZIPPER & GIRGOL
------------------------------------------
E, S, GET ZIPPER [10], OPEN ZIPPER,  REACH IN ZIPPER, GET SCROLL [10], BLORPLE
"earth", D,  D, WAIT (UNTIL  IN ROC NEST),  GET SCROLL [10],  BLORPLE "earth",
GNUSTO CASKLY, S, GET SCROLL [10], GNUSTO  THROCK, U, PUSH ROCK, GIRGOL, U, U,
U, U,  GET COIN, W,  LEARN CASKLY, CASKLY HUT,  GET CUBE [25],  LEARN BLORPLE,
BLORPLE CUBE

SOFT ROOM — LIFE CUBE
---------------------
S, WRITE "soft"  ON CUBE, PUT SOFT AND COIN  IN ZIPPER,  PULL WEED, PULL WEED,
LEARN BLORPLE,  BLORPLE "earth", W, N, PLANT WEED,  LEARN THROCK, THROCK WEED,
D,  GET ALL [20], U, S, GNUSTO ESPNIS, OPEN BOX, GET CUBE  [25], WRITE "water"
ON CUBE, LEARN BLORPLE, BLORPLE "water"

WATER ROOM — WATER CUBE
-----------------------
LEARN BLORPLE, PUT ALL BUT "earth" AND  BREAD IN ZIPPER, CLOSE ZIPPER, S, DROP
BREAD, GET  CUBE, GET BOTTLE, BLORPLE  "earth", OPEN BOTTLE, GET  SCROLL [10],
OPEN ZIPPER, GET BOOK, GNUSTO LISKON, DROP BOTTLE, E, N, SLEEP

SNAKE TEMPLE
------------
LEARN LISKON,  LISKON SNAKE, N,  N, "LEARN ESPNIS,MALYON", MALYON  IDOL, WAIT,
ESPNIS IDOL,  WAIT, CLIMB IDOL,  GET CUBE [25], D,  GET BURIN, WRITE  "air" ON
CUBE, "LEARN BLORPLE,BLORPLE", PUT ALL BUT  "air" AND BURIN IN ZIPPER, BLORPLE
"air"

AIR ROOM — AIR CUBE
-------------------

BUY BLUE  CARPET, OFFER  400, OFFER 450,  OFFER 500, GET  BLUE [10],  W, LEARN
BLORPLE, GET "water", BLORPLE "water"

WATER ROOM AGAIN — DEATH CUBE
-----------------------------
"LEARN TINSOT,TINSOT,TINSOT",  PUT ALL BUT  BURIN IN ZIPPER, CLOSE  ZIPPER, N,
TINSOT WATER, TINSOT  WATER, TINSOT WATER, CLIMB ICE, WAIT,  REZROV TRAP DOOR,
U, GET  CUBE [25],  WRITE "bone"  ON CUBE,  OPEN ZIPPER,  GET CARPET,  U, DROP
CARPET, SIT ON CARPET, U, W, W, W,  W, D, STAND, GET CUBE [25], WRITE "string"
ON CUBE, SIT ON CARPET, U, E, E, E,  E, D, STAND, D, E, N, REZROV CABINET, GET
BOOK [10],  GET SPELL BOOK,  LEARN CASKLY,  CASKLY MOLDY [15],  GNUSTO SNAVIG,
LEARN BLORPLE, BLORPLE "string"

NO PLACE / THE PLAIN — MIND CUBE
--------------------------------
SLEEP, S, GIVE FRAGMENT TO ROCK, CLIMB ROCK, (YOU NEED TO CATCH THE BROWN-EYED
ROCK, IT TRIES TO MOVE AWAY FROM YOU. BELOW IS A SUGGESTION ON ONE WAY TO TRAP
IT. IT MIGHT NOT WORK, SO KEEP TRYING  TO CORNER IT. THE MAP GROUND LOOKS LIKE
THIS:

"ROCK, W", "ROCK, NE", "ROCK, E", "ROCK,  S", "ROCK, S", (IF BROWN GOES NORTH,
THEN GO NORTH THEN  SOUTH. IF BROWN GOES WEST, THEN GO  SOUTH)", JUMP TO BROWN
ROCK, GET CUBE [25], WRITE "dark" ON CUBE, LEARN BLORPLE, BLORPLE "dark"

GRUE,  D, CLIMB PILLAR, GET  CUBE [25], D,  U, U, WAIT (UNTIL  YOU HAVE BECOME

BLORPLE "fire", E,  GET CUBE [25], WRITE "magic" ON  CUBE, GET "nplace", LEARN
BLORPLE, BLORPLE "nplace"

THE VAULT — COIN WEIGHING PUZZLE
--------------------------------
E, "LEARN JINDAK,JINDAK,JINDAK,BLORPLE", PUT ALL IN ZIPPER, REZROV DOOR, SAVE,
N, (YOU NEED TO FIND THE ODD CUBE,  THIS CUBE IS RANDOM. FOLLOW THESE STEPS TO
FIND THE ODD ONE, IF YOU DON'T MAKE IT TO THE SAND ROOM, START AGAIN),

-- STEP 1: GET  X1,X2,X7,X8, JINDAK (IF EVEN -> STEP 2.  IF UNEVEN, NOTE WHICH
PILE IS BRIGHTER -> STEP 5)

-- STEP 2: GET X3,X4, PUT X1,X2 ON FIRST, JINDAK (IF EVEN -> STEP 3. IF UNEVEN
-> STEP 4)

-- STEP 3: GET  X1, PUT X7 ON FIRST, JINDAK (IF EVEN  -> BLORPLE X8. IF UNEVEN
-> GET X7, BLORPLE X7. THEN STEP 9)

-- STEP 4: GET  X1, PUT X7 ON FIRST, JINDAK (IF EVEN  -> BLORPLE X1. IF UNEVEN
-> GET X2, BLORPLE X2. THEN STEP 9)

-- STEP 5:  PUT X1,X2,X7 ON SECOND,  GET X9,X10,X11,X12, PUT X9  ON FIRST, GET
X6, PUT X6 ON SECOND, JINDAK (IF EVEN ->  STEP 6. IF SAME AS STEP 1 -> STEP 7.
IF OPPOSITE TO STEP 1 -> STEP 8)

-- STEP 6: GET ALL (IF CAN'T PICK  UP ALL, PUT X1,X2,X3,X4 IN ZIPPER), PUT X10
ON FIRST, PUT X11 ON SECOND, JINDAK (IF EVEN -> BLORPLE X12. IF SAME AS STEP 5
-> GET X11, BLORPLE X11. IF OPPOSITE -> GET X10, BLORPLE X10. THEN STEP 9)

-- STEP 7: GET  ALL (IF CAN'T PICK UP ALL, PUT  X9,X10,X11,X12 IN ZIPPER), PUT
X3 ON FIRST, PUT X4 ON SECOND, JINDAK  (IF EVEN -> BLORPLE X5. IF SAME AS STEP
1 -> GET X3, BLORPLE X3. IF OPPOSITE -> GET X4, BLORPLE X4. THEN STEP 9)

-- STEP 8: GET  ALL (IF CAN'T PICK UP ALL, PUT X2,X3,X4,X5  IN ZIPPER), PUT X6
ON FIRST, PUT  X1 ON SECOND, JINDAK (IF  EVEN -> BLORPLE X9. IF  UNEVEN -> GET
X6, BLORPLE X6. THEN STEP 9)

-- STEP  9: IF YOU  LAND IN  THE SAND ROOM,  YOU SUCCEEDED. IF  IN NONDESCRIPT
ROOM, RESTORE AND RETRY. [25]
