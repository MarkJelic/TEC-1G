AIM: SAVE BELBOZ FROM JEEAR

NOTE: IF A SWARM OF BLOODSUCKING  LOCUSTS APPEARS ON THE HORIZON, MOVE OUT OF
THAT LOCATION AND COME BACK

GUILD HALL
----------

S [5], FROTZ ME,  STAND, W, S, S, W, GET VIAL AND  MATCHBOOK, OPEN VIAL, DRINK
POTION [10], E, OPEN MAILBOX, PUT  MATCHBOOK IN MAILBOX, WAIT (UNTIL MESSENGER
ARIVES), OPEN MAILBOX, GET  VIAL [10], E, GET SCROLL [10],  GNUSTO MEEF, W, N,
N, W, OPEN DESK, PULL HANGING [15],  GET KEY, OPEN JOURNAL, READ JOURNAL (NOTE
THE CURRENT CODE  WORD), DROP ALL BUT BOOK  AND ORANGE, E, S, S,  D,

(BASED ON THE CODE WORD IN THE JOURNAL, PUSH THE FOLLOWING BUTTONS:

BLOODWORM: WHITE GRAY BLACK RED GRAY
BROGMOID:  RED PURPLE RED BLACK PURPLE
DORN: GRAY PURPLE BLACK GRAY WHITE
DRYAD: BLACK GRAY WHITE RED RED
GRUE: BLACK BLACK RED BLACK PURPLE
HELLHOUND:  PURPLE WHITE GRAY RED GRAY
KOBOLD:  RED PURPLE BLACK PURPLE RED
NABIZ: PURPLE BLACK BLACK BLACK RED
ORC:  RED GRAY PURPLE GRAY RED
ROTGRUB: GRAY RED GRAY PURPLE RED
SURMIN: BLACK BLACK PURPLE RED PURPLE
YIPPLE:  GRAY PURPLE WHITE PURPLE BLACK ) [25],

GET SCROLL, AIMFIZ BELBOZ [20]

FOREST, RIVER, FORT & CHASM
---------------------------

NE, LEARN  PULVER, E,  NE, PULVER  RIVER, D,  NE [20],  GET SCROLL  AND GUANO,
GNUSTO FWEEP, D,  S, W, D, W, SW, SW,  W, LEARN IZYUK, IZYUK ME, W,  W, N, GET
COIN [15], S,  E, LEARN IZYUK, IZYUK  ME, E, E, N,  U, U, E, NE,  SE, E, LOWER

LEARN IZYUK, LEARN IZYUK, IZYUK ME, NW, SW, IZYUK ME, E, E, D, D, E, SLEEP

GLASS MAZE
----------

WAKE GNOME, GIVE  COIN [10],  SEARCH GNOME, E, E, N,  N, LEARN FWEEP,
LEARN FWEEP, LEARN FWEEP, FWEEP ME, E, N, E, S,  S, W, D, E, E, N, N, U, U, S,
E, GET SCROLL [20], DROP SCROLL IN CHIMNEY, FWEEP  ME, W, W, S, E, D, D, W, W,
U, U, N, N, D, E, FWEEP ME, S, E, N, D, W, S, W, U, W, WAIT, WAIT, GET ALL, S,
S, E, GET SCROLL [25], GNUSTO SWANZO

AMUSEMENT PARK
--------------

W, W,  W, W, W, SW,  SW, S, SW,  W, GIVE COIN, W,  W, S, GET BALL,  OPEN AQUA,
DRINK POTION, THROW BALL  AT BUNNIES [10], GNUSTO MALYON, DROP  AQUA, N, E, E,
NE, S, SLEEP, YONK MALYON, LEARN MALYON, MALYON DRAGON, S [20]

COAL MINE
---------

E, OPEN VIAL, DRINK
POTION, DROP  VIAL, (NOTE COMBINATION  NUMBER FROM  TWIN), GIVE BOOK,  E, TURN
DIAL TO  [NUMBER], OPEN DOOR [20],  E, GET ROPE, U,  SW, GET BEAM, NW,  W, TIE
ROPE TO BEAM, PUT  BEAM ACROSS CHUTE, THROW ROPE INTO  CHUTE, CLIMB DOWN [20],
GET SCROLL, GOLMAC  ME, OPEN LAMP, GET SMELLY [25],  D, "TWIN, THE COMBINATION
IS [NUMBER]", WAIT, D [20], WAIT (UNTIL EXHAUSTED), SLEEP

DEFEATING JEEARR
----------------

"LEARN MEEF,MEEF,SWANZO", DROP  ALL, E, D,  MEEF WEEDS,
OPEN CRATE [15], GET  SUIT, U, W, GET ALL, NE, N, MEEF  VINES, W, W [20], OPEN
WHITE [20], VARDIK ME, SWANZO BELBOZ [25]

(YOU WIN! WITH 400/400 POINTS)
