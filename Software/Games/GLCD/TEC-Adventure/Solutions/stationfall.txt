AIM: DISCOVER WHY STATIONFALL IS ABANDONED AND DESTROY THE EVIL WITHIN

NOTES: WHEN  PLATO TRIES  TO KILL  YOU TYPE  REPETITIVELY, "FLOYD,  HELP" [7]
UNTIL HE  IS DEAD.  THEN "GET ALL"  AS YOU  DROP ALL YOUR  STUFF. IF  A HULK
WELDER SHOWS UP, MOVE TO ANOTHER ROOM AND THEN BACK AGAIN.

ABOARD THE S.P.S DUFFY
----------------------

(NOTE: THE  NUMBER TO  TYPE IN TO  DIRECT THE CRAFT  IS BASED ON THE CURRENT
TIME OF THE GAME. IF 343 DOESN'T WORK, REFER TO THE ORIGIANL GAME DOCUMENTS) 

E, N, INSERT ROBOT FORM IN SLOT, TYPE  3, S, E, OPEN HATCH, IN, CLOSE HATCH,
GET KIT, SIT IN  PILOT SEAT, INSERT SPACECRAFT FORM IN  SLOT, TYPE 343, OPEN
KIT, OPEN BOTTLE, EMPTY BOTTLE, GET BOTTLE, WAIT, WAIT, WAIT, WAIT, WAIT [5]

OBTAIN FORM TO EXIT COMMAND MODULE
----------------------------------

STAND, OPEN HATCH, OUT, E, NE, N, N, N,  U, GET BOARD, D, S, S, S, SW, D, D,
EAT ORANGE, OPEN CAN,  GET FORM, U, U, U, U, NW,  OPEN PRESSER, PUT CRUMPLED
IN PRESSER, CLOSE PRESSER, TURN PRESSER  ON, OPEN PRESSER, GET IRONED, E, D,
D, SE, SE, E, LOOK UNDER BED, GET STAMP, STAMP IRONED FORM, W, N, NE, INSERT
IRONED IN SLOT [6]

UPGRADE ID AND GET HYPERDIODE
-----------------------------

E, E, E, GET  LAMP, WEAR LAMP, W, SW, OPEN CAGE, SE,  SE, INSERT ID IN SLOT,
TURN MACHINE ON,  TYPE 9, GET ID, PUT  ID IN POCKET, D, W, SW,  GET CAN, NE,
NE, U, N, N, SPRAY CAN, W, SPRAY  CAN, W, SPRAY CAN, W, SPRAY CAN, NW, SPRAY
CAN,  SW, SRPAY  CAN, U,  SPRAY CAN,  U, SPRAY  CAN, SW,  OPEN PULPUT,  FLIP
SWITCH, SPRAY CAN,  TAKE LEASH, GET STAR [7], D,  OPEN STAR, GET HYPERDIODE,
DROP STAR, KIT, CAN, STAMP AND FORM

GET AND FIX DETONATOR AND SLEEP 
-------------------------------

E, U, N,  GET DETONATOR, OPEN DETONATOR, GET BLACKENED,  PUT M HYPERDIODE IN
DETONATOR, CLOSE DETONATOR,  DROP BLACKENED, SW, D,  D, D, D, SE,  PUT ID IN
READER, N [5], GET GUN, S, W, U,  NE, E, GET IN BED, SLEEP [3] (REPEAT UNTIL
ASLEEP)

GET FOIL AND TIMER WITH THE HELP FROM AN OSTRICH
------------------------------------------------

STAND, GET ALL, W, SE,  SW, S, S, S, SE, S, SHOOT BOX,  GET COIN [5], N, NE,
U, NW, EXAMINE CEILING,  OPEN PANEL, GET NIP [3], NE,  SE, BREAK MIRROR, GET
FOIL [4], W, OPEN BAG, EAT TAFFY, S, D, SW, SE, SCARE OSTRICH, NW, NW, N, N,
N, NE, NW, NE, PUT COIN IN SLOT, PRESS 6, SCARE OSTRICH [6], GET TIMER, DROP
NIP

SET UP JAMMER AND DRILL HOLE IN SAFE
------------------------------------

W, TURN  LAMP ON,  W, GET  JAMMER, S, TURN  LAMP OFF,  S, CONNECT  JAMMER TO
BOARD, SET JAMMER TO  710, DROP JAMMER, SE, S, W,  WAIT (FOR FLOYD), "FLOYD,
GET DRILL BIT",  GET BIT [3], E, N, NW,  D, D, NW, GET DRILL, SE,  U, U, SE,
SE, E, GET SMALL  BIT, INSERT MEDIUM BIT IN DRILL, DRILL  HOLE IN SAFE, DROP
DRILL, CONNECT TIMER TO DETONATOR, DROP TIMER AND DETONATOR

GO INTO SPACE TO GET EXPLOSIVE
------------------------------

W, N, NE, E, E, S, SE, E, TURN WHEEL [4], U, OPEN LOCKER, GET SUIT, D, W, W,
SE, D, GET BOOTS, WEAR BOOTS, W,  NE, OPEN HATCH, D, CLOSE HATCH, WEAR SUIT,
TURN LAMP ON, OPEN OUTER DOOR, D  [3], READ LABEL, U, PUT FREZONE IN BOTTLE,
CLOSE BOTTLE, CLOSE OUTER DOOR, TAKE  OFF SUIT, TURN LAMP OFF, REMOVE BOOTS,
DROP BOOTS AND SUIT, OPEN INNER DOOR, U

BLOW UP SAFE AND DESTROY THE PYRAMID
------------------------------------

TURN LAMP ON, SW,  NW, N, N, E, N, E, OPEN BOTTLE,  GET FREZONE, PUT FREZONE
IN HOLE [3],  CONNECT DETONATOR TO FREZONE,  SET TIMER TO 10, W,  E, GET KEY
[7], W, NW, NW, GET JAMMER, U, U, U, U, UNLOCK BIN, OPEN BIN, GET JAMMER AND
FOIL AND GUN, OPEN  GRATING, ENTER AIR SHAFT [2], D, D, D,  D, D, D, D, OPEN
GRATING, TURN JAMMER ON, TURN JAMMER  OFF, U [2], SHOOT FLOYD, COVER PYRAMID
WITH FOIL [5]

(YOU WIN! WITH 80/80 POINTS)
